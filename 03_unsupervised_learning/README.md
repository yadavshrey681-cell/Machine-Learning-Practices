# Unsupervised Learning

Explores pattern discovery, clustering algorithms, and dimensionality reduction techniques without labeled targets.

## Modules
- **`clustering_algorithms.py`**: K-Means clustering with Elbow Method and Silhouette Analysis, alongside density-based clustering (DBSCAN).
- **`pca_dimensionality_reduction.py`**: Principal Component Analysis (PCA) for variance decomposition, compression, and 2D visualization.

## How to Run
```bash
python 03_unsupervised_learning/clustering_algorithms.py
python 03_unsupervised_learning/pca_dimensionality_reduction.py
```
