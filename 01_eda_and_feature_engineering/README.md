# Exploratory Data Analysis & Feature Engineering

This module covers practical workflows for inspecting datasets, treating missing values, handling outliers, encoding categorical features, scaling numeric variables, and feature selection.

## Contents
- **`eda_pipeline.py`**: Automated exploratory analysis script producing dataset summaries, missing value profiles, skewness, and correlation analyses.
- **`feature_engineering_utils.py`**: Reusable feature transformers (outlier capping, standard/min-max scaling, categorical encoding, polynomial interactions).

## Quick Run
```bash
python 01_eda_and_feature_engineering/eda_pipeline.py
python 01_eda_and_feature_engineering/feature_engineering_utils.py
```
