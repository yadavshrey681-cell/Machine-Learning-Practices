# Supervised Learning

Implementations and comparisons of foundational algorithms for both continuous (regression) and categorical (classification) targets.

## Modules
- **`regression_models.py`**: Ordinary Least Squares (OLS), Ridge (L2), Lasso (L1), and ElasticNet with cross-validation.
- **`classification_models.py`**: Logistic Regression, Decision Trees, and Support Vector Machines (SVM) with hyperparameter tuning.
- **`ensemble_methods.py`**: Bagging vs Boosting — Random Forests and Gradient Boosted Trees compared against base estimators.

## How to Run
```bash
python 02_supervised_learning/regression_models.py
python 02_supervised_learning/classification_models.py
python 02_supervised_learning/ensemble_methods.py
```
